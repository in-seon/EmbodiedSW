# 팀 인터페이스 합의 필요 사항

CLAUDE.md 6장 기준, 목표 2(쓰러짐 감지) 팀원 및 하드웨어팀과 합의가 필요한 항목.
합의되는 대로 이 문서를 갱신하고 `config/config.py`의 해당 값을 채운다.

- [ ] 신호 연장 누적 상한 (초 단위)
- [ ] 교통약자 우선 연장 규칙 (연장 폭 차등 여부, 별도 상한 여부)
- [ ] 라즈베리파이-아두이노 통신 프로토콜 (포트, 보드레이트, 메시지 포맷)
- [ ] 목표 2 파이프라인과 사람 검출 모델/좌표계 공유 여부
- [ ] 7세그먼트 표시 정보 (잔여 시간 vs 기타)
- [ ] 카메라 설치 각도/높이 실측값
