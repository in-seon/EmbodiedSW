# 스마트 신호등 프로젝트 — AGENTS.md

**이 프로젝트의 컨텍스트 문서는 [CLAUDE.md](CLAUDE.md) 하나다.** 어떤 에이전트로 작업하든
(Codex, Claude Code 등) CLAUDE.md를 읽고 그 규칙을 따른다.

이 파일은 원래 CLAUDE.md의 Codex용 복사본이었는데, 두 벌을 각각 고치다 보니 내용이 어긋났다
(카메라 구도·하드웨어 구성·폴더 구조가 전부 옛 버전으로 남아 있었다). 같은 내용을 두 곳에
두면 반드시 다시 어긋나므로, 사본을 없애고 포인터만 남긴다.

## 빠른 요약

- 담당 파트는 **목표 1: 보행자 잔류 감지 기반 신호 연장**. (목표 2 쓰러짐 감지는 팀원 담당)
- 카메라는 **보행자 신호등에 부착되어 횡단보도를 사선으로 비춘다** (탑뷰 아님).
- 위치 판정 기준점은 bounding box **하단 모서리의 중심**(발 위치). 중심점이 아니다.
- 속도는 **호모그래피로 평면 좌표(cm)로 편 뒤** 계산한다. 실측 치수가 없으면 px/s로 떨어진다.

## 반드시 지킬 것 (CLAUDE.md 5장)

- 팀과 확정되지 않은 값(연장 초, 상한, 통신 프로토콜 등)을 **임의로 확정하지 말 것.**
  config에 `None`으로 두고, 사용 지점에서 `NotImplementedError`로 멈추게 한다.
- 모델 성능(FPS, 정확도) 수치를 **실측 없이 추정치로 기록하지 말 것.**
- 라즈베리파이 자원 제약을 고려해 경량 접근을 우선 검토할 것.
- 파라미터를 정한 근거를 `docs/` 또는 커밋 메시지에 남길 것.

자세한 내용은 전부 [CLAUDE.md](CLAUDE.md)에 있다. 미확정 항목 목록은
[docs/team_interface.md](docs/team_interface.md) 참고.
